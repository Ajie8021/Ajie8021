# 四则运算项目测试报告

## 1. 测试概述

### 1.1 测试目的

本项目是一个基于 Java 实现的四则运算题目自动生成与批改程序。测试工作的主要目标是验证程序是否满足需求规格说明中的功能要求，并检查各模块之间的协作是否正确。

本次测试重点验证以下内容：

- 分数的精确计算是否正确；
- 四则运算表达式的计算是否正确；
- 表达式合法性验证是否正确；
- 表达式去重与等价判断是否正确；
- 四则运算题目的随机生成是否满足要求；
- 表达式解析是否正确；
- 命令行参数处理是否正确；
- 答案批改功能是否正确；
- 文件输入输出是否正常；
- 异常输入能否得到正确处理；
- 程序生成大量题目时是否能够正常运行。

### 3.1 单元测试

按照项目目录结构，将测试代码划分到不同模块：

```tex

│  └─ FractionTest.java

│  └─ ExpressionCalculatorTest.java
├─ validator/
```

### 4.4 ExpressionNormalizer 模块

测试文件：

```tex
ExpressionNormalizerTest.java
```

该模块重点测试题目要求中的等价表达式判断。

测试：

```tex
3 + 5
5 + 3
```

应当视为重复。

同样：

```tex
3 × 5
5 × 3
```

应当视为重复。

同时验证更复杂的情况：

```tex
3 + (2 + 1)
```

和：

```tex
(1 + 2) + 3
```

应当判断为等价。

但是：

```tex
(3 + 2) + 1
```

与：

```tex
(1 + 2) + 3
```

不能仅通过有限次交换左右子节点得到，因此不应判断为重复。

测试结果：**全部通过**。
